# Classificador de Nível de Herói

Primeiro desafio de lógica de programação proposto no bootcamp da DIO.

## Sobre o desafio

A ideia foi criar um classificador que, com base na quantidade de XP (experiência) de um herói, determina em qual nível ele se encontra usando estruturas condicionais.

## Classificação

| XP | Nível |
|----|-------|
| Menos de 1.000 | Ferro |
| 1.001 a 2.000 | Bronze |
| 2.001 a 5.000 | Prata |
| 5.001 a 7.000 | Ouro |
| 7.001 a 8.000 | Platina |
| 8.001 a 9.000 | Ascendente |
| 9.001 a 10.000 | Imortal |
| Acima de 10.001 | Radiante |

## Saída esperada

```
O Herói de nome {nome} está no nível de {nivel}
```

## Como rodar

```bash
node index.js
```
